# Security policy

Please report vulnerabilities privately. Do not open a public issue.

- Use GitHub private vulnerability reporting: open the Security tab of this repository and choose "Report a vulnerability".
- A dedicated address, security@heisenbughq.com, will be added here once mail routing is set up.

Include what you found, how to reproduce it, and the version affected. Reports are handled by the maintainer as quickly as possible. Please give a reasonable time to fix before disclosing publicly.
